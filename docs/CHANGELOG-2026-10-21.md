# گزارش تغییرات — 2026-10-21

این بسته بر مبنای `khanegi-store-upgraded.zip` قبلی اصلاح شده است؛ پروژه از نو ساخته نشده.

## تغییرهای این مرحله

- وقتی Supabase در حالت واقعی تنظیم شده باشد، کاتالوگ با فهرست خالی شروع می‌شود. اگر خواندن دیتابیس شکست بخورد، محصولات نمونه نمایش داده نمی‌شوند و پیام خطا نشان داده می‌شود تا قیمت‌های نمایشی با قیمت فروش اشتباه نشوند.
- خروجی CSV محصولات و سفارش‌های بارگذاری‌شده در پنل مدیریت اضافه شده است. فایل CSV دارای BOM برای سازگاری بهتر با Excel است و سلول‌های شبیه فرمول برای کاهش خطر CSV injection خنثی می‌شوند.
- ساخت محصول پیش‌نویس و ثبت موجودی اولیه به RPC تراکنشی `create_product_draft_secure` منتقل شده تا شکست مرحله دوم باعث باقی‌ماندن محصول بدون موجودی نشود.
- نقش `super_admin` اضافه شده و تابع `has_role` نقش‌ها را سلسله‌مراتبی ارزیابی می‌کند. مهاجرت، هیچ حسابی را خودکار مدیر یا super-admin نمی‌کند.
- مجوز `UPDATE` جدول سفارش محدود شده به ستون `status` برای کاربران authenticated. کلاینت مرورگر دیگر نباید بتواند `payment_status` را تغییر دهد؛ تأیید پرداخت باید در مسیر سروری مورداعتماد انجام شود.
- CSS واکنش‌گرا برای خروجی‌های پنل و پیام خطای کاتالوگ اضافه شده است.

## مواردی که هنوز عملیاتی نشده‌اند

درگاه پرداخت، تأیید callback سمت سرور، ارسال واقعی، کوپن/تخفیف، بارگذاری تصویر، CRUD کامل دسته‌بندی و برند، گزارش‌های مالی کامل، واردسازی CSV، نرخ ارز زنده، اتصال تأییدشده ترب و SEO مبتنی بر SSR/prerender هنوز تکمیل نشده‌اند. این بسته نباید بدون پیکربندی و آزمون محیط staging به‌عنوان فروشگاه آماده دریافت پول منتشر شود.

## اعتبارسنجی

در محیط تولید این بسته، `npm run build` اجرا شد اما به‌دلیل نبود وابستگی‌های نصب‌شده و در دسترس نبودن نصب موفق پکیج‌ها، TypeScript نتوانست ماژول‌هایی مانند `react` و `vite` را پیدا کند. بنابراین build و تست‌ها در این محیط تأیید نشده‌اند. پس از دریافت فایل، اجرا کنید:

```powershell
npm install
npm test
npm run build
```

مهاجرت SQL در دیتابیس واقعی اجرا نشده است. ابتدا در پروژه Supabase آزمایشی، با CLI و backup مناسب، migrationها را بررسی و اجرا کنید.
